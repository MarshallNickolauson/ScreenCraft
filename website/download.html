Download ScreenCraft

A free, open-source screen recorder and editor. No account, no watermark, no subscription. Version 0.4.0.

macOS

Apple Silicon and Intel · macOS 14 or later · .dmg

Or install with one command. It skips the macOS security prompt and opens ScreenCraft for you:

curl -fsSL https://screencraft.mdnlabs.dev/install.sh | bash

Prefer the disk image? macOS will ask you to approve it once (steps below):

Download for macOS
  1. Open screencraft_0_4_0.dmg and drag ScreenCraft to Applications.
  2. The app is not notarized, so macOS blocks it the first time. Open System Settings → Privacy & Security, scroll down, click Open Anyway next to ScreenCraft, then confirm. (Or run xattr -dr com.apple.quarantine /Applications/ScreenCraft.app in Terminal.)
  3. Allow Screen Recording when asked (Microphone, Camera and Accessibility are optional), then relaunch.

Windows

Windows 10 (1903+) or 11 · 64-bit · .exe installer
Download for Windows
  1. Run screencraft_0_4_0.exe. It installs for your user and needs no administrator rights.
  2. The installer is unsigned, so SmartScreen may warn. Choose More info, then Run anyway.
Early alpha. The Windows build is new and has had less testing than the macOS one. Please report problems on GitHub.
